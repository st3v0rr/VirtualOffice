# LPC character layers

Layers from the [Universal LPC Spritesheet Character Generator](https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Character-Generator)
(`spritesheets/`), cut down by `client/scripts/prepare-lpc.sh` to the rows the office uses
(walk, idle, sit, run; 64x64 cells, rows up/left/down/right).

The graphics are licensed under CC-BY-SA 3.0 / GPL 3.0 (some also OGA-BY / CC-BY),
see `CREDITS.csv` for the authors and licenses of every file. Changes: only rows were removed.
